Installing GlassDo

Tasks, sticky notes, an edge panel and system meters in one app. Everything stays on this Mac.

  • Tasks and notes that live on your desktop
  • CPU, memory, disk and network meters
  • Window switcher and shelf
  • File transfer from an Android phone over USB

GlassDo opens by itself once the installation finishes. On first launch it asks for Accessibility and Screen Recording permissions, which the window switcher and the meters rely on.
